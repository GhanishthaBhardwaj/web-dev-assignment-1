# Smart Utility Toolkit

A Node.js CLI-based toolkit built using only core modules (`process`, `http`, `fs`, `crypto`) — no external packages. Includes a calculator (`calculator.js`), a reusable module demo (`app.js`), an HTTP server with `/`, `/about`, `/contact` routes (`server.js`), a file manager for CRUD operations (`fileManager.js`), and a crypto-based dice roller (`dice.js`).

**Run examples:** `node calculator.js add 5 3` · `node server.js` (visit `localhost:3000`) · `node dice.js 5` · `node fileManager.js create test.txt "hello"`
